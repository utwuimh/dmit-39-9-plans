# DMIT 39.9：月付和年付两种买法差在哪，入门档配置、线路与当前库存一次说清

搜「DMIT 39.9」的人，通常是在论坛或群里看到一句话——「四十美元一年，三网优化线路，移动快乐机」——然后兴冲冲打开官网，发现价格表里 $39.9 出现在好几个地方，配置还完全不一样。

问题出在 39.9 这个数字在 DMIT 的价格体系里指两件不同的事：一个是**年付 $39.9 的美西特价机**，一个是**月付 $39.9 的香港/东京 Premium 入门档**。两者价格只差一个周期，实际能拿到的东西差着量级。

先把这两者分开，后面所有选择都好办了。

## 年付 $39.9 的特价机，配置和线路到底什么水平

以被讨论最多的 LAX.AN4.EB.WEE 为例，规格如下：

- 1 vCPU（AMD EPYC 平台）、1GB 内存、20GB SSD
- 1000GB 月流量，1Gbps 端口
- 1 个 IPv4 + 1 个 IPv6 /64
- Eyeball 网络配置（面向终端访问优化的中间档线路）
- $39.90/年

线路这块要留个心眼。第三方整理对回程口径的说法并不一致：有的写「三网回程 CMIN2」，也有测评写「移动回程 CMIN2、电信联通回程走 AS9929」，去程则多为电信/联通走 CN2、移动走 CMIN2。这种差异在小商家那儿通常意味着路由被调整过。下单前建议直接看官网产品页的路由说明，别只看论坛截图。

延迟表现上，多个测评给出的全国平均区间大约在 130ms–180ms，移动网络因为双向 CMIN2 的加持，晚高峰的稳定性评价普遍不错。这个成绩放在美西机器里属于正常偏好的一档，但指望它和香港机器比延迟就不现实了。

几个容易忽略的限制：

**流量超了会降速，不会停机。** WEE 这一档超出流量后一般降到 2Mbps 左右继续跑，轻量任务还能用，做重流量中转就明显难受了。

**不是流媒体解锁机。** 有测评提到 LAX EB 的 IPv4 解锁不了 Netflix、Disney+ 这类主流平台，但 ChatGPT、TikTok 没有问题。如果你的核心用途是看流媒体，该看的是 Pro 系列或其他方案。

**硬盘和 CPU 别抱幻想。** 20GB SSD 装完系统剩不下多少，跑个轻量博客、面板、代理中转、开发测试机刚好。

## 现在还能买到 $39.9/年的那款吗

这是搜这个词的人最该知道的一条变化：**LAX.AN4 产品线已经被官方下线，取而代之的是 LAX.AN5 系列**，主机平台从 AMD EPYC 9004 时代升到 9005，价格门槛也跟着上移，目前洛杉矶系列月付最低 $12.98 起。

也就是说，年付 $39.9 那台机器属于上一代平台的限量特价库存，会不定期补货，补完即止。有第三方整理在 AN4 系列售罄后写得很直白：该系列最便宜的常规款变成了打折后年付约 71 美元的 LAX.EB.TINY。

所以看到「$39.9 一年」的帖子，先确认发布日期。如果是几个月前的，那批货大概率已经没了；能捡到属于运气，不是常态。

## 月付 $39.9 的香港 Premium 是什么水平

如果 39.9 你打算按「月」来花，香港 HKG.Pro TINY 是这一档里最值得看的：1核 1G、20GB SSD、500GB 月流量、1Gbps 端口，$39.9/月。

它的价值全在线路上。这个系列走三网回程经香港 CTG 接入国内 CN2 GIA，电信去程 CN2 GIA 直连香港 CTG，联通走 AS4837 + AS10099，移动走香港 CMI 直连。第三方引用的实测数据显示，香港 Premium 全国三网平均延迟可以压到 43ms 左右，电信、联通、移动都在 42–46ms 区间，丢包极少。

换算一下：$39.9/月 ≈ 年付 478 美元左右。它和年付 39.9 那台机器差的是「一年四十块」和「一个月四十块」，用途也完全不同——一个拿来跑小项目和练手，一个拿来跑有国内访问要求的正式业务。

值得一提的是，香港 Pro 已经升级到 HKG.AN5.Pro（AMD EPYC 9005 + DDR5），官方公布的起售价同样是 $39.9/月。老 AS3 平台与新 AN5 平台在部分档位上价格接近，下单时留意自己买的是哪一代。

## 优惠码：哪些能用，哪些根本用不上

DMIT 的促销逻辑和其他商家不太一样，值得单独说。

它很少放「全网通用」的大额折扣，更常见的做法是**循环折扣码 + 账户金返还**组合。循环折扣意味着续费同价，不是只便宜第一个周期；账户金返还则是按比例把部分已付金额退到账户余额里，通常分月返还，用来抵扣下一次账单。

两类码的适用范围差异很大：

- 面向常规计划（Pro / EB 等）的码，一般从某档配置起才可用
- 面向 Tier 1 系列的码，通常明确写「不含 WEE」
- **限量特价机基本不接受优惠码**，这条几乎在所有活动帖里都被反复提到。所以别指望在原价 $39.9/年的机器上再叠一层折扣

使用方法倒是简单：在购物车页面选好套餐和付款周期，输入优惠码后点 Validate Code 验证，能过才会显示折后价。不同码对应不同产品线和付款周期，拿 Pro 的码去下单 T1 大概率验证失败。

另外网上流传的一些码，比如年付七折、半年付八折的 Lite 系列循环码，多数标注「仅适用于 STARTER 及以上规格」，而且发布时间较早。这类码是否还有效，最稳妥的办法就是在购物车里验证一次——过了就是有效，没过就别纠结。

## 三个容易踩的规则

**退款政策。** 官方 TOS 第 19 条是退款条款，第三方整理的说法是前三天可全额退款，30 天内按比例退款。想试线路的话，三天窗口基本够跑一轮测速。

**免费换 IP。** 各来源口径不太统一：有说每 15 天可以免费换一次被封的 IP，也有说实例激活超过 7 天、或剩余有效期大于 7 天时可以申请。具体细则建议直接看官网 TOS，不要按论坛帖子里的说法去规划。

**付款方式。** 支持支付宝、微信、PayPal 和主流信用卡，有中文客服。这也是它在中文用户里存在感高的原因之一。

## 到底该不该买这一档

按需求拆开看，判断会清楚很多：

- **只是想花小钱练手、跑轻量服务、做个开发测试机**：等有 $39.9/年 的特价机补货就上，性价比确实高。但要做好随时售罄的准备，别为了这个价位把项目进度卡住。
- **面向国内用户的正式站点或服务**：年付 39.9 那台 1G 内存的机器不是合适的选择。直接看香港 Premium 或洛杉矶 Pro，$39.9/月 换 43ms 级别的延迟和 CN2 GIA 回程，这笔钱花在线路上。
- **主要客户在海外**：Tier 1 系列更划算。$36.9/年 起，端口大、流量多，价格低一截，只是别指望国内访问速度。
- **需要流媒体解锁**：避开 Eyeball 系列，去 Pro 系列里挑。

一个提醒：DMIT 的库存策略是限量放货，热门方案经常在几小时内清空。看到有货还在犹豫的时候，先算清楚自己的流量和内存需求，比反复刷帖子有用。

## 常见问题

**$39.9/年 的机器现在还能买到吗？**
属于限量特价库存，不定期补货、补完即止，官方不保证长期在售。AN4 平台的特价机在被 LAX.AN5 系列替代后，常规最低门槛已经上移到月付 $12.98 左右。

**和月付 $39.9 的套餐是同一个东西吗？**
不是。年付 39.9 是美西低配特价机，月付 39.9 是香港/东京 Premium 入门档，配置、线路等级和适用场景都不同。

**支持支付宝吗？**
支持，同时支持微信、PayPal 和信用卡。

**特价机能叠加优惠码吗？**
普遍不能，这类机器通常被明确排除在优惠码适用范围之外。

**流量用完了会停机吗？**
洛杉矶系列是降速不限量，日本 Premium 有整理提到超量后会暂停服务。不同系列规则不一样，下单前看清楚产品页说明。
